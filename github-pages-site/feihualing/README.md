# 上传说明

这个目录用于覆盖你仓库里的 `github-pages-site/` 目录。

## 正确上传方式

把本目录中的文件上传到 GitHub 的这个位置：

`pugna2232.github.io/github-pages-site/`

需要上传的是本目录里面的文件：

- `index.html`
- `.nojekyll`
- `README.md`

不要再把 `github-pages-site-root-upload` 这个外层文件夹上传进去。

上传后，下面这个网址会直接显示飞花令游戏：

`https://biwabokubo1996.github.io/pugna2232.github.io/github-pages-site/`

如果你继续保留 `feihualing-github-pages` 子文件夹，那么它的访问地址是：

`https://biwabokubo1996.github.io/pugna2232.github.io/github-pages-site/feihualing-github-pages/`
