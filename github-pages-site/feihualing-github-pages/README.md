# 飞花令小游戏

这是一个纯前端单页网页游戏，不需要后端或构建工具。

## 上传到 GitHub Pages

1. 新建一个 GitHub 仓库。
2. 上传本目录里的所有文件到仓库根目录：
   - `index.html`
   - `.nojekyll`
   - `README.md`
3. 打开仓库 `Settings` -> `Pages`。
4. 在 `Build and deployment` 里选择：
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
5. 保存后等待 GitHub Pages 部署完成。

部署完成后，GitHub 会给出一个类似这样的访问地址：

`https://你的用户名.github.io/仓库名/`

## 本地预览

直接双击 `index.html`，或使用任意静态服务器打开即可。
